## Overview
Data is a collection of facts or numbers gathered to answer a question. The chapter shows how to **collect** and **organise** data (tally marks, frequency tables) and how to **present** it so it is easy to read — pictographs, bar graphs and infographics — and warns about presentations that mislead.

---

## Key Terms & Definitions
| Term | Definition |
|---|---|
| Data | A collection of facts, numbers or observations gathered to give information about a question. |
| Raw data | Data in the form it was collected, not yet organised. |
| Tally marks | Strokes used to count: |, ||, |||, ||||, and the 5th stroke drawn **across** the four (𝍸). Grouping in fives makes counting quick. |
| Frequency | The **number of times** a value occurs in the data. |
| Frequency table | A table listing each value (or group) with its tally and frequency. |
| Pictograph | Data shown using **pictures/symbols**, with a **key** saying how much one symbol stands for. |
| Key / Scale | The value of one symbol (pictograph) or one unit of length (bar graph), e.g. 1 symbol = 10 students. |
| Bar graph | Data shown with **bars of equal width and equal gaps**, whose lengths are proportional to the values. |
| Infographic | An artistic, eye-catching presentation that mixes pictures, numbers and graphs. |

## Core Concepts

### 1. Collecting and organising data
1. Decide the question (e.g. "What is the favourite fruit of my class?").
2. Collect the raw data.
3. Organise it: list each category, mark one tally stroke per observation, then write the frequency.
- **Check:** the frequencies must add up to the total number of observations.
- For marks or measurements with many different values, group them in classes like 10–19, 20–29, … before tallying.

### 2. Pictographs
- Choose a symbol and a **key** that makes the symbol counts small whole numbers (or halves).
- Value = number of symbols × key. Half a symbol = half the key.
- Example: key 1 📘 = 120 books → 840 books = 7 symbols; 300 books = 2½ symbols.
- Drawback: hard to show values that aren't simple fractions of the key; drawing many symbols takes time.

### 3. Bar graphs
- Two axes: one shows the categories, the other the values with a **uniform scale**.
- All bars have **equal width** and **equal gaps** between them; only the length shows the value.
- Choosing a scale: look at the largest value and pick a scale so the tallest bar fits (e.g. largest 840 → 1 unit = 100).
- Always **mention the scale** and label both axes and give the graph a title.
- Bars can be vertical or horizontal.

### 4. Reading graphs
- Read the bar length against the scale.
- Compare: "how many more", "how many times", "total", "highest/lowest".

### 5. Misleading presentations
If the value axis does not start at 0, or the bars/symbols are of different widths/sizes, a small difference can look huge. Always check the scale.

---

## Important Rules / Formulas
- Value from pictograph = number of symbols × key.
- Bar length = value ÷ scale.
- Sum of frequencies = total observations.

## Solved Examples
### Example 1
Books sold in a week: 240, 720, 480, 600, 840, 360, 720 (Mon–Sun). Draw a pictograph.
**Solution:**
1. All values are multiples of 120 → key 1 📘 = 120 books.
2. Symbols: Mon 2, Tue 6, Wed 4, Thu 5, Fri 7, Sat 3, Sun 6.
3. Draw rows of symbols and write the key.

### Example 2
Bar graph scale 1 unit = 25 kg. How long is the bar for 175 kg?
**Solution:** 175 ÷ 25 = **7 units**.

## Exercise Questions (typical)
1. Make a frequency table with tally marks from raw data.
2. Draw a pictograph with a suitable key.
3. Draw a bar graph (e.g. your PT-1 marks out of 40 in all subjects) with a suitable scale.
4. Read a bar graph and answer questions.

---

## Quick Summary
- Raw data → tally → frequency table.
- Pictograph: symbols + key.
- Bar graph: equal widths, equal gaps, uniform scale starting at 0, title and labels.
- Watch out for misleading scales.
